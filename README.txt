使用方式
1. 將 ZIP 解壓縮。
2. 將 index.html、data.js、README.txt、slides 資料夾上傳 GitHub 儲存庫根目錄。
3. 在 GitHub Settings → Pages → Deploy from a branch → master（或 main）→ /(root) → Save。
4. 開啟 GitHub Pages 網址，即可觀看。
